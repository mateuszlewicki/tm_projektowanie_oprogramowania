# Materiały do przedmiotu Projektowanie Oprogramowania

prowadzący - inż. Mateusz Lewicki

Drodzy Państwo, przedstawiam wam repozytorium na którym znajdują się materiały wymagane do zajęć, omówione na zajęciach oraz zagadnienia dodatkowe.

Zawartość tego repozytorium będzie sukcesywnie aktualizowana. Zastrzegam sobie prawo i zobowiązuje się, by materiały pojawiły się w ciągu 2 tygodni od zajęć. W przypadkach, gdy nie będę się wywiązywał, proszę do mnie napisać.
